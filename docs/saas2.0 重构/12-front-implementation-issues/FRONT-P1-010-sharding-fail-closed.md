# FRONT-P1-010 分库配置异常时错误回退默认数据源

- 状态：CLOSED
- 优先级：P1
- 影响：租户数据可能被写入错误数据库，属于数据隔离风险。

## 证据

- tenantId 为空时返回第一个数据源。
- 目标数据源不存在时返回第一个数据源。
- 配置客户端未注入、配置缺失、字段缺失或异常时返回 `ds_0`。

## 验收标准

1. tenantId 为空立即失败。
2. 配置客户端未注入、配置不存在、JSON 无效、data_source_id 缺失均明确失败。
3. 解析出的 `ds_x` 不在可用列表时明确失败。
4. 不再存在 `ds_0` 或第一个数据源兜底。
5. 范围查询策略若可能跨租户访问，需按实际业务约束明确限制，不默认广播写操作。
