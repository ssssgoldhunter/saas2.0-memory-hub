# agent-environment — Agent 环境复现包

> 在**第二台电脑**上重建与当前机器一致的 DeepSeek Harness 开发环境。

## 目录内容

| 文件 | 用途 |
|------|------|
| `ENVIRONMENT.md` | **总入口**：环境清单、插件/MCP/Skill 使用规则、凭据、新电脑搭建步骤 |
| `DSH.md` | DSH 工作手册副本（部署到 `~/.dsh/AGENTS.md`） |
| `开发操作手册.md` | 高级工程师行为准则副本（部署到记忆体 `docs/开发操作手册.md`） |
| `presets/ssss-dsh/` | ssss dsh 智能体预设（部署到 `~/.ohdsh/.agent-presets/ssss-dsh/`） |
| `start-web.sh` | Web 版 harness 一键启动脚本（监听 127.0.0.1:3080） |

## 使用

1. 先读 `ENVIRONMENT.md`（含全部事实 + 搭建步骤）。
2. 手册部署表见 `ENVIRONMENT.md` §8。
